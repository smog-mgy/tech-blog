    循环神经网络（RNN）学习笔记¶

    日期：2026-04-30 标签：深度学习 · RNN · 学习笔记

    一、RNN 介绍¶

    1.1 什么是 RNN¶

    循环神经网络（Recurrent Neural Network, RNN）= 专门处理序列数据的神经网络。

    • 与传统前馈神经网络不同，RNN 具有 "循环"结构
    • 能处理和记住前面时间步的信息
    • 特别适用于时间序列数据或有时序依赖的任务

    1.2 什么是序列数据¶

    序列数据 = 在不同时间点上收集到的数据，反映事物随时间的变化状态或程度。

    • 不一定是时间：也可以是文字序列
    • 序列数据的核心特点：后面的数据跟前面的数据有关系

    例子："我爱你"——"爱"必须在"我"之后、"你"必须在"爱"之后，颠倒顺序意思就变了。为了表示这种序列关系，就需要 RNN。

    1.3 RNN 的应用¶

    领域 应用
    自然语言处理（NLP） 文本生成、语言建模、机器翻译、情感分析
    时间序列预测 股市预测、气象预测、传感器数据分析
    语音识别 将语音信号转换为文字
    音乐生成 通过学习音乐的时序模式生成新乐曲

    1.4 自然语言处理（NLP）概述¶

    NLP = 通过计算机算法来理解自然语言。 处理的数据主要是人类语言（汉语、英语、法语等）。

    难点：语言数据不像结构化数据或图像数据那样方便数值化——所以需要词嵌入层先把文本变成向量。

    二、词嵌入层¶

    2.1 词嵌入层的作用¶

    词嵌入层 = 将文本转换为向量。

    在 RNN 中的作用： 1. 输入表示：把词变成网络能算的向量 2. 降低维度：把高维稀疏表示压缩成低维稠密向量 3. 捕捉语义相似性：意思相近的词向量更接近

    核心思想：根据词的数量构建一个词向量矩阵。例如有 100 个词，每个词转成 128 维向量 → 矩阵形状 100×128，每个词对应矩阵中的一行。

    2.2 词嵌入层工作流程¶

    初始化词向量（随机 或 加载 Word2Vec/GloVe 预训练向量）
→ 输入索引（分词后每个词在词表中有一个唯一索引）
→ 查找词向量（把索引映射为低维稠密向量，表示词的语义）
→ 输入到 RNN（词向量作为输入，RNN 根据上下文生成输出）

    2.3 PyTorch 词嵌入 API¶

    embed = nn.Embedding(num_embeddings=10, embedding_dim=4)

    两个核心参数： - num_embeddings：词的数量 - embedding_dim：用多少维的向量表示每个词

    2.4 词嵌入使用示例¶

    把文本分词 → 构建词表 → 用 nn.Embedding 获取每个词的向量：

    import torch
import torch.nn as nn
import jieba    # 中文分词库，需安装：pip install jieba

if __name__ == '__main__':
    # 0. 文本数据
    text = '北京冬奥的进度条已经过半，不少外国运动员在完成自己的比赛后踏上归途。'
    # 1. 文本分词
    words = jieba.lcut(text)
    print('文本分词:', words)
    # ['北京冬奥', '的', '进度条', '已经', '过半', '，', '不少', '外国', '运动员', '在',
    #  '完成', '自己', '的', '比赛', '后', '踏上', '归途', '。']
    # 2. 分词去重（set 会乱序，这里用列表手动去重保持顺序）
    unique_words = list(set(words))
    print("去重后词的个数:\n", len(unique_words))
    # 3. 构建词嵌入层
    embed = nn.Embedding(num_embeddings=len(unique_words), embedding_dim=4)
    print("词嵌入的结果：\n", embed)
    # 4. 每个词的词向量表示
    for i, word in enumerate(unique_words):
        word_vec = embed(torch.tensor(i))   # 输入词的索引，输出词向量
        print('%3s\t' % word, word_vec)

    总结：文本 → 分词 → 词表（词↔索引映射）→ nn.Embedding 查表 → 词向量，这就是文本数值化的标准流程。

    三、循环网络层（RNN 核心）¶

    3.1 RNN 网络原理¶

    关键概念：隐藏状态 h（RNN 的记忆）

    • h 保存了序列数据中的历史信息，并传递给下一个时间步
    • 每次输入包含两个值：上一个时间步的隐藏状态 + 当前输入 x
    • 每次输出也包含两个值：当前时间步的隐藏状态 + 当前预测结果 y

    隐藏状态（h）的作用： 1. 记忆功能：像 RNN 的记忆，在不同时间步之间传递信息；新输入结合当前隐藏状态生成新隐藏状态 2. 上下文理解：携带过去的信息，用于理解和生成与上下文相关的输出（语言模型、机器翻译等） 3. 连接不同时间步：通过循环连接把各时间步串起来，能处理变长序列

    3.2 重要认知：只有一个神经元！¶

    画了 3 个神经元，但实际上只有一个神经元——"我爱你"三个字是重复输入到同一个神经元中（展开成多个时间步只是便于理解）。

    文本生成例子：输入"我爱"预测"你"：

    初始化 h0（一般全 0 向量）
→ "我"词嵌入 → 送入第 1 时间步 → 输出 h1
→ h1 + "爱"词嵌入 → 送入第 2 时间步 → 输出 h2
→ h2 送入全连接网络 → 得到"你"的预测概率

    3.3 RNN 神经元内部计算（两个公式）¶

    ① 计算隐藏状态：

    ht = tanh(Wih·xt + bih + Whh·ht-1 + bhh)
    符号 含义
    Wih / bih 输入数据的权重 / 偏置
    Whh / bhh 输入隐藏状态的权重 / 偏置
    ht-1 输入隐藏状态（上一个时间步）
    ht 输出隐藏状态（当前时间步）

    最后用 tanh 激活函数得到当前输出隐藏状态。

    ② 计算当前时刻的输出：

    yt = Why·ht + by
    • yt：当前时刻输出（RNN 层的预测值向量）
    • ht：当前时刻隐藏状态
    • Why：隐藏状态到输出的权重矩阵
    • by：输出层偏置

    ③ 词汇表映射：输出 yt 经过全连接层得到最终预测 Ypred，Ypred 里每个元素代表词汇表中某个词的得分（经 softmax 变成概率）。词汇表有多少词，Ypred 就有多少元素，最大元素对应的词就是预测生成的词。

    3.4 神经元工作机制总结（三步）¶

    1. 接收输入：每个 RNN 神经元接收输入数据 xt 和前一时刻隐藏状态 ht-1
    2. 更新隐藏状态：通过加权和（权重矩阵+偏置）更新 ht，包含过去的记忆和当前输入的信息
    3. 输出计算：基于 ht 生成输出 yt，用于最终预测

    3.5 文本生成示例（预测流程）¶

    输入"m" → 词向量 x1
→ 初始化 h0=0
→ 更新 h1，计算 y1
→ 全连接输出 ypred，softmax 转概率分布
→ 选概率最高的词（如"a"）
→ 把"a"作为新输入，继续下一个时间步
→ 直到生成完整句子

    3.6 PyTorch RNN API¶

    rnn = torch.nn.RNN(input_size, hidden_size, num_layers)

    参数： - input_size：输入数据维度（一般设为词向量维度） - hidden_size：隐藏层 h 的维度（当前层神经元的输出维度） - num_layers：隐藏层 h 的层数，默认 1

    输入输出：

    output, hn = rnn(x, h0)
    项 形状 含义
    输入 x [seq_len, batch, input_size] 句子长度、batch 大小、词向量维度
    输入 h0 [num_layers, batch, hidden_size] 层数、batch、隐藏层 h 维度
    输出 output [seq_len, batch, hidden_size] 每个时间步的输出
    输出 hn [num_layers, batch, hidden_size] 最后一层的隐藏状态 
    import torch
import torch.nn as nn

def test():
    # 词向量维度 128，隐藏向量维度 256
    rnn = nn.RNN(input_size=128, hidden_size=256)
    # inputs: [句子长度5, 批量32, 词向量维度128]
    inputs = torch.randn(5, 32, 128)
    # hn: [网络层数1, 批量32, 隐藏向量维度256]
    hn = torch.zeros(1, 32, 256)
    output, hn = rnn(inputs, hn)
    print("输出向量的维度：\n", output.shape)   # torch.Size([5, 32, 256])
    print("隐藏层输出的维度：\n", hn.shape)      # torch.Size([1, 32, 256])

if __name__ == '__main__':
    test()

    记忆：RNN 的输入输出都是三维的，区别只在中间维度（input_size → hidden_size）。

    四、案例：周杰伦歌词生成¶

    4.1 项目需求¶

    文本生成任务：输入一个开始词，预测出后面的词序列。

    本案例用循环神经网络实现周杰伦歌词生成：收集了周杰伦第一张专辑《Jay》到第十张专辑《跨时代》的歌词（共 5819 行文本）训练模型，训练好后用模型创作歌词。

    实现流程：

    构建词汇表 → 构建数据对象 → 编写网络模型 → 编写训练函数 → 编写预测函数

    4.2 导入工具包¶

import torch.nn as nn
import torch.nn.functional as F

    4.3 构建词表（build_vocab）¶

    词表 = 分词后给每个词分配唯一编号，便于送入词嵌入层获取词向量。

    # 获取数据，并进行分词，构建词表
def build_vocab():
    # 数据集位置
    file_name = 'data/jaychou_lyrics.txt'
    # 分词结果存储位置
    unique_words = []     # 去重后的词
    all_words = []        # 所有分词结果（含重复）

    # 遍历数据集中的每一行文本
    for line in open(file_name, 'r'):
        # 使用 jieba 分词，结果是列表
        words = jieba.lcut(line)
        all_words.append(words)
        # 遍历分词结果，去重
        for word in words:
            if word not in unique_words:
                unique_words.append(word)

    # 语料中词的数量
    word_count = len(unique_words)

    # 词到索引的映射（词表）
    word_to_index = {word: idx for idx, word in enumerate(unique_words)}

    # 整个语料库的词索引表示
    corpus_idx = []
    for words in all_words:
        temp = []
        for word in words:
            temp.append(word_to_index[word])
        # 每行词之间加空格索引隔开
        temp.append(word_to_index[' '])
        corpus_idx.extend(temp)

    return unique_words, word_to_index, word_count, corpus_idx

if __name__ == "__main__":
    unique_words, word_to_index, word_count, corpus_idx = build_vocab()
    print("词的数量：\n", word_count)
    print("去重后的词:\n", unique_words)
    print("每个词的索引：\n", word_to_index)
    print("当前文档中每个词对应的索引：\n", corpus_idx)

    词表包含：unique_words（每个词）、word_to_index（词→编号映射）、corpus_idx（全文词的编号序列）

    4.4 构建数据集对象（LyricsDataset）¶

    把语料切成 "输入 num_chars 个词 → 预测下一个词" 的样本对：

    class LyricsDataset(torch.utils.data.Dataset):
    def __init__(self, corpus_idx, num_chars):
        # 文档中词的索引
        self.corpus_idx = corpus_idx
        # 每个句子中词的个数
        self.num_chars = num_chars
        # 词的总数量
        self.word_count = len(self.corpus_idx)
        # 句子数量 = 总词数 // 每句词数
        self.number = self.word_count // self.num_chars

    def __len__(self):
        return self.number

    def __getitem__(self, idx):
        # 修正索引到文档范围
        start = min(max(idx, 0), self.word_count - self.num_chars - 2)
        # 输入值：前 num_chars 个词
        x = self.corpus_idx[start: start + self.num_chars]
        # 目标值：往后错一位的 num_chars 个词（预测下一个词）
        y = self.corpus_idx[start + 1: start + 1 + self.num_chars]
        return torch.tensor(x), torch.tensor(y)

if __name__ == "__main__":
    dataset = LyricsDataset(corpus_idx, 5)
    x, y = dataset.__getitem__(0)
    print("网络输入值：", x)
    print("目标值：", y)

    核心思想：用前 N 个词预测第 N+1 个词，x 和 y 刚好错开一位。

    4.5 构建网络模型（TextGenerator）¶

    三层结构： 1. 词嵌入层：语料 → 词向量 2. 循环网络层：提取句子语义 3. 全连接层：输出对词典中每个词的预测概率

    class TextGenerator(nn.Module):
    def __init__(self, word_count):
        super(TextGenerator, self).__init__()
        # 词嵌入层：词向量维度 128
        self.ebd = nn.Embedding(word_count, 128)
        # 循环网络层：词向量维度128，隐藏向量维度128，1层
        self.rnn = nn.RNN(128, 128, 1)
        # 输出层：128维 → 词表中词的个数
        self.out = nn.Linear(128, word_count)

    def forward(self, inputs, hidden):
        # 词嵌入：输出维度 (batch, seq_len, 128)
        embed = self.ebd(inputs)
        # RNN 要求输入 (seq_len, batch, 128)，所以 transpose 前两维
        output, hidden = self.rnn(embed.transpose(0, 1), hidden)
        # 展平后过全连接：输出 (seq_len*batch, word_count)
        output = self.out(output.reshape((-1, output.shape[-1])))
        return output, hidden

    def init_hidden(self):
        # 隐藏状态初始化：[层数, batch, 隐藏维度]
        return torch.zeros(1, 1, 128)

    4.6 构建训练函数¶

    文本生成本质是分类问题（预测下一个词是词表中的哪个）→ 用多分类交叉熵损失；优化器选 Adam（学习率、梯度自适应）。

    def train():
    # 构建词典
    index_to_word, word_to_index, word_count, corpus_idx = build_vocab()
    # 数据集
    lyrics = LyricsDataset(corpus_idx, 32)
    # 初始化模型
    model = TextGenerator(word_count)
    # 损失函数
    criterion = nn.CrossEntropyLoss()
    # 优化方法
    optimizer = optim.Adam(model.parameters(), lr=1e-3)
    # 训练轮数
    epoch = 10

    for epoch_idx in range(epoch):
        # 数据加载器
        lyrics_dataloader = DataLoader(lyrics, shuffle=True, batch_size=1)
        start = time.time()
        iter_num = 0
        total_loss = 0.0
        for x, y in lyrics_dataloader:
            # 隐藏状态初始化（每个样本重新初始化）
            hidden = model.init_hidden()
            # 模型计算
            output, hidden = model(x, hidden)
            # y: [batch, seq_len] → [seq_len, batch] → [seq_len*batch]
            y = torch.transpose(y, 0, 1).contiguous().view(-1)
            loss = criterion(output, y)
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            iter_num += 1
            total_loss += loss.item()
        print('epoch %3s loss: %.5f time %.2f' % (epoch_idx + 1, total_loss / iter_num, time.time() - start))
    # 模型存储
    torch.save(model.state_dict(), 'data/lyrics_model_%d.pth' % epoch)

if __name__ == "__main__":
    train()

    4.7 构建预测函数¶

    预测思想：输入第一个指定词 → 送入网络预测出下一个词 → 再把预测出的词送入网络 → 循环直到指定长度。

    def predict(start_word, sentence_length):
    # 构建词典
    index_to_word, word_to_index, word_count, _ = build_vocab()
    # 构建模型并加载参数
    model = TextGenerator(word_count)
    model.load_state_dict(torch.load('data/lyrics_model_10.pth'))
    # 隐藏状态
    hidden = model.init_hidden()
    # 将起始词转换为索引
    word_idx = word_to_index[start_word]
    # 存储生成的词索引
    generate_sentence = [word_idx]

    # 循环预测下一个词
    for _ in range(sentence_length):
        output, hidden = model(torch.tensor([[word_idx]]), hidden)
        # 取概率最大的词索引
        word_idx = torch.argmax(output)
        generate_sentence.append(word_idx)

    # 把索引转回词并打印
    for idx in generate_sentence:
        print(index_to_word[idx], end='')

if __name__ == "__main__":
    predict('分手', 50)

    结尾 · 总结¶

    整体流程：

    构建词汇表 → 构建数据对象 → 编写网络模型 → 编写训练函数 → 编写预测函数

    本章核心知识点一览：

    • RNN = 处理序列数据的神经网络，通过隐藏状态 h 记住历史信息
    • 序列数据特点：后面的数据跟前面的数据有关系（如"我爱你"不能颠倒）
    • 词嵌入层 nn.Embedding(num_embeddings, embedding_dim)：文本 → 词向量（文本数值化标准流程：分词 → 词表 → 查表）
    • 隐藏状态公式：ht = tanh(Wih·xt + bih + Whh·ht-1 + bhh)；输出：yt = Why·ht + by
    • RNN API：nn.RNN(input_size, hidden_size, num_layers)，输入输出都是三维 [seq_len, batch, dim]
    • 文本生成本质是分类问题：交叉熵 + Adam，前 N 个词预测第 N+1 个词
    • 案例：周杰伦歌词生成（词表 → Dataset → TextGenerator → train → predict）
