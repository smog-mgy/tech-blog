    LLM 主流开源大模型学习笔记¶

    前置：这篇里所有模型的"模型结构"部分，都是在拿 Decoder-only / Prefix-Decoder 架构做对比。看完你就能回答面试常问的"这几个开源模型各有什么特点？"

    一、LLM 主流大模型类别（总览）¶

    ChatGPT 火爆后引发大模型时代变革，国内外近百款大模型发布。开源语言大模型主要有四大家族 + Qwen：

    模型 开发方 衍生模型
    ChatGLM 清华大学 wenda、ChatSQL 等
    LLaMA Meta AI Alpaca、Vicuna、BELLE、Phoenix、Chimera 等
    BLOOM Hugging Face Bloomz、BELLE、Phoenix 等
    Baichuan 百川智能 Baichuan-7B、13B、Baichuan2-13B 等
    Qwen（通义千问） 阿里巴巴 Qwen、Qwen1.5、Qwen2、Qwen2.5 系列

    二、ChatGLM-6B（中文支持最好的早期开源模型）¶

    2.1 简介¶

    • 清华大学提出，开源、支持中英双语的对话模型
    • 基于 GLM（General Language Model）架构，62 亿参数
    • 使用与 ChatGPT 相似的技术：约 1T 标识符中英双语训练（比例 1:1）+ 监督微调 + 反馈自助 + RLHF
    • 优点：当时中文支持最好

    2.2 训练目标（GLM 核心思想）¶

    GLM = 基于自回归空白填充目标的通用预训练框架。

    原理： 1. 在输入文本中随机挖去一些连续的文本片段（用 [M] 替换） 2. 打乱片段顺序（捕捉跨度间内在联系） 3. 训练模型按任意顺序自回归重建这些片段

    通俗理解：把文章挖掉几段话，让模型像做完形填空一样把被挖掉的段落"重新写出来"——既是填空（双向），又是生成（自回归）。

    关键符号：[M]=MASK，[S]=START，[E]=END；Part A 的词互相可见、看不到 Part B；Part B 的词可以看到 Part A 和 Part B 前面的词。

    2.3 模型结构（核心改动点）¶

    采用 Transformer 的 Decoder 模块，但属于 Prefix-Decoder（某些位置可看到双向，因此得名"类 decoder"）。相比原始 Decoder 的改动：

    改动点 说明
    Embedding 层梯度缩减 梯度缩小 10 倍，提升训练稳定性
    Layer Normalization 采用基于 Deep Norm 的 post layer norm
    激活函数 ReLU → GeGLU
    位置编码 去掉绝对位置编码 → RoPE 旋转位置编码

    2.4 模型配置与硬件要求¶

    配置项 数值
    参数 6.2B
    隐藏层维度 4096
    层数 28
    注意力头数 32
    训练数据 1T
    词表大小 130528
    最大长度 2048

    硬件要求（推理/微调最低显存）：

    量化等级 推理 高效参数微调
    FP16（无量化） 13GB 14GB
    INT8 10GB 9GB
    INT4 6GB 7GB

    记忆点：INT4 量化只需 6GB 显存 → 可以部署在消费级显卡上（这就是它当年火的原因——普通人有显卡就能跑）。

    2.5 优缺点¶

    优点： - 部署门槛低（INT4 只要 6GB 显存） - 人类意图对齐训练 - ChatGLM2-6B 升级后支持 32K 长序列（第一代 2K）

    缺点： - 模型容量小，记忆和语言能力相对较弱 - 多轮对话能力较弱

    2.6 衍生应用¶

    • langchain-ChatGLM：基于 langchain 的可扩展知识库问答
    • 闻达：大型语言模型调用平台，实现类 ChatPDF 功能

    2.7 迭代版本（了解）¶

    • ChatGLM2-6B：性能大幅提升（数学任务 +571%）、FlashAttention 支持 32K 上下文、Multi-Query Attention 推理提速 42%
    • ChatGLM3-6B：多模态理解 SOTA、代码增强模块、网络搜索增强

    三、LLaMA（Meta 的开源基础模型，衍生模型之王）¶

    3.1 简介与训练目标¶

    • Meta AI 于 2023 年发布，开放且高效的大型基础语言模型
    • 版本：7B、13B、33B、65B（650 亿）四种
    • 训练数据：以英语为主的拉丁语系 + GitHub 代码数据，不包含中韩日文
    • 65B/33B 在 1.4T token 上训练；7B/13B 在 1T token 上训练
    • 训练目标：语言模型——根据已有的上文预测下一个词（Causal LM）

    Tokenizer 特点：BPE 分词，词表只有 32000；中文 token 只有几百个 → 对中文编码效率低

    3.2 模型结构（Decoder-only）¶

    和 GPT 系列一样是 Decoder-only，改动点：

    改动点 说明
    Normalization Pre Layer Norm + RMSNorm（去掉减去均值的部分）
    激活函数 ReLU → SwiGLU
    位置编码 绝对位置编码 → RoPE

    3.3 模型配置（7B）¶

    配置项 数值
    参数 6.7B
    隐藏层维度 4096
    层数 32
    注意力头数 32
    训练数据 1T
    词表大小 32000
    最大长度 2048

    训练成本感受一下：65B 模型在 2048 个 80G A100 GPU 上，380 tokens/sec/GPU，训练 1.4T tokens 需要 21 天。

    3.4 优缺点¶

    优点： - 13B 的 LLaMA 在大多数基准上胜过 GPT-3（1750 亿参数）——小模型大能量 - 可以在单块 V100 GPU 上运行 - 65B 媲美 Chinchilla-70B、PaLM-540B

    缺点： - 会产生偏见性、有毒或虚假内容 - 中文效果差（语料不含中文，一个汉字可能切成多个 token，编码效率低）

    3.5 衍生应用（重点记）¶

    衍生模型 说明
    Alpaca 斯坦福，52k 英文指令数据微调 7B LLaMA
    Vicuna UC Berkeley，ShareGPT 用户共享对话微调 13B
    BELLE 仅用 ChatGPT 生成的数据对 LLaMA 指令微调，针对中文优化
    Chinese LLaMA 扩充中文词表：用中文语料训练 20000 词的 SentencePiece tokenizer，与原 tokenizer 合并 → 词表 49953

    3.6 迭代版本（了解）¶

    • LLaMA 2：训练语料多 40%、上下文 2048→4096、注重安全隐私、出 chat 版本（SFT + RLHF）
    • LLaMA 3：词表扩到 128k、用 GQA 分组查询注意力提速、预训练数据超 15T token（比 Llama 2 大 7 倍）

    四、BLOOM（Hugging Face 的多语言模型）¶

    4.1 简介与训练目标¶

    • Hugging Face 训练的大语言模型
    • 训练数据：46 种语言 + 13 种编程语言，1.5TB 去重清洗文本，中文占 16.2%
    • 参数规模：560M、1.1B、1.7B、3B、7.1B、176B
    • 训练目标：语言模型，根据上文预测下一个词

    Tokenizer：多语种语料上训练 BPE，词表大小 250880

    4.2 模型结构（Decoder-only）¶

    改动点 说明
    激活函数 GeLU
    Embedding Layer Norm embedding 层后加 layer norm，训练更稳定
    Normalization Pre Layer Norm
    位置编码 绝对位置编码 → ALiBi 相对位置编码（外推性更好）

    4.3 模型配置（176B）¶

    配置项 数值
    参数 176B
    隐藏层维度 14336
    层数 70
    注意力头数 112
    训练数据 366B
    词表大小 250880
    最大长度 2048

    训练成本：384 张 A100 80GB GPU，训练约 3.5 个月（约 100 万计算时），算力成本超过 300 万欧元。

    4.4 优缺点¶

    优点：良好的多语言适应性，多语言间切换无需重新训练 缺点：会产生偏见性、有毒或虚假内容

    4.5 衍生应用¶

    • 轩辕：金融领域大模型，度小满基于 BLOOM-176B 对中文通用+金融领域预训练与微调
    • BELLE：用 ChatGPT 生成的数据对 BLOOMZ-7B1-mt 指令微调

    五、Baichuan-7B（百川智能的开源可商用模型）¶

    5.1 简介与训练目标¶

    • 百川智能 2023 年 6 月发布，开放且可商用的预训练模型
    • 支持中英双语，约 1.2T token 训练的 70 亿参数模型
    • 训练目标：语言模型，根据上文预测下一个词
    • Tokenizer：BPE，词表 64000
    • 数据：开源中英文数据 + 自行抓取的中文互联网数据 + 高质量知识性数据

    5.2 模型结构（和 LLaMA 一样的 Decoder-only）¶

    改动点 说明
    Pre-normalization Pre Layer Norm + RMSNorm（简化 Layer Norm，减少约 7%~64% 计算时间）
    激活函数 SwiGLU
    位置编码 RoPE

    5.3 模型配置（7B）¶

    配置项 数值
    参数 7B
    隐藏层维度 4096
    层数 32
    注意力头数 32
    训练数据 1.2T
    词表大小 64000
    最大长度 4096

    5.4 模型特点¶

    • 通用性强：NLP、机器翻译、问答系统、智能客服、金融、医疗、教育等应用前景大
    • 在中文 C-EVAL 和英文 MMLU 权威 benchmark 上同参数规模最好效果

    5.5 迭代版本：Baichuan-13B¶

    1. 更大：130 亿参数，训练 1.4T tokens，ALiBi 位置编码，上下文 4096
    2. 更高效：开源 int8/int4 量化版，可部署在 Nvidia 3090 消费级显卡
    3. 免费可商用：学术开放，邮件申请即可免费商用

    六、Qwen（阿里的通义千问系列）¶

    6.1 简介¶

    • 阿里巴巴训练并开源的一系列大模型
    • 2023 年 8 月开源 7B，随后陆续开源 4 个规模版本（最低 1.8B，最高 720B）
    • 系列：Qwen、Qwen1.5、Qwen2、Qwen2.5（热门）

    6.2 模型结构（Decoder-only）¶

    改动点 说明
    GQA 分组查询注意力 减少 KV 缓存使用，提升推理效率
    激活函数 SwiGLU
    位置编码 RoPE（提升长序列处理能力）
    Layer Norm RMSNorm（训练稳定）

    6.3 模型配置（Qwen2.5-7B-Instruct）¶

    配置项 数值
    参数 7B
    隐藏层维度 3584
    层数 28
    注意力头 28 个 query、4 个 key-value
    训练数据 1.2T
    词表大小 151936
    最大长度 32768（32K）

    6.4 模型特点¶

    • Qwen2.5 预训练用了高达 18 万亿 token（Qwen2 是 7 万亿）
    • 后训练引入复杂监督微调 + 多阶段强化学习
    • 长文本生成、结构化数据分析、指令遵循能力显著提升

    自测题（思考总结）：

    问题 答案
    ChatGLM-6B 的模型架构？ Prefix-Decoder-Only（基于 GLM 自回归空白填充）
    ChatGLM-6B 的训练目标？ 随机挖去连续文本片段，训练模型按任意顺序重建
    ChatGLM-6B 的改动点？ Embedding 梯度缩减、Deep Norm、GeGLU、RoPE
    LLaMA 的模型架构？ Decoder-only（同 GPT 系列）
    LLaMA 的训练目标？ 根据已有上文预测下一个词
    LLaMA 的改动点？ RMSNorm（Pre LN）、SwiGLU、RoPE
    BLOOM 的模型架构？ Decoder-only
    BLOOM 的改动点？ Embedding LN、Pre LN、GeLU、ALiBi
    Baichuan-7B 的模型架构？ 和 LLaMA 一致，Decoder-only
    Baichuan-7B 的改动点？ Pre LN、SwiGLU、RoPE
    Qwen-2.5 的模型架构？ 基于 Transformer 的 Decoder-only（Causal Model）
    Qwen-2.5 的改动点？ GQA、RMSNorm、SwiGLU、RoPE

    发现规律了吗开源模型的结构改动几乎都是"三件套"——激活函数换 SwiGLU/GeGLU、Norm 换 RMSNorm/Pre-LN、位置编码换 RoPE**。
