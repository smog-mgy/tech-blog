    LLM 主要架构学习笔记¶

    前置：深度学习进入大模型领域。之前学的 Transformer 相关知识（自注意力、Encoder/Decoder）会在这里派上用场。读完这篇，你就知道为什么现在的 ChatGPT、DeepSeek、Qwen 都叫"Decoder-only"架构了。

    一、LLM 主要类别（先看总览）¶

    LLM 本身基于 Transformer 架构（2017 年《Attention is all you need》诞生）。

    基于原始 Transformer 框架，衍生出三类模型：

    类别 英文 使用模块 代表作 擅长
    自编码模型 AutoEncoder (AE) 只用 Encoder BERT 内容理解（NLU）
    自回归模型 Autoregressive (AR) 只用 Decoder GPT 内容生成（NLG）
    序列到序列 Sequence to Sequence Encoder + Decoder 都用 T5 理解 + 生成

    记忆口诀：编码器管"看懂"，解码器管"说话"，两个都用是"翻译"。

    二、自编码模型（AE）—— 代表作 BERT¶

    2.1 什么是自编码模型¶

    • 特点：Encoder-Only（只用编码器）
    • 基本原理：在输入中随机 MASK 掉一部分单词，根据上下文预测这个词（完形填空）
    • 通常用于内容理解任务（NLU）：情感分析、提取式问答、文本分类

    2.2 BERT 简介¶

    BERT = Bidirectional Encoder Representation from Transformers（双向 Transformer 编码器表示）

    • 2018 年 10 月由 Google AI 提出
    • 里程碑成就：在 SQuAD1.1 机器阅读理解测试中全面超越人类，11 种 NLP 测试创 SOTA（GLUE 80.4%、MultiNLI 86.7%）

    2.3 BERT 架构（三大模块）¶

    宏观上 BERT 分三个模块：

    ┌─────────────────────────────┐
│  预微调模块（最上层）         │ ← 根据任务调整
├─────────────────────────────┤
│  Transformer 模块（中间层）   │ ← 双向编码（核心）
├─────────────────────────────┤
│  Embedding 模块（最底层）     │ ← Token + Segment + Position
└─────────────────────────────┘

    ① Embedding 模块：由三种 Embedding 直接相加得到

    类型 作用
    Token Embeddings 词嵌入，第一个单词是 [CLS] 标志（用于分类任务）
    Segment Embeddings 句子分段嵌入（服务"两句话输入"的预训练任务）
    Position Embeddings 位置编码

    ② 双向 Transformer 模块：BERT 只用了经典 Transformer 的 Encoder 部分，完全舍弃 Decoder。两大预训练任务都在这里完成。

    ③ 预微调模块：最后一层根据任务需求调整。例如序列分类任务：取第一个 [CLS] token 的 final hidden state → 全连接层 → softmax → 预测标签。

    2.4 BERT 的预训练任务（两个）¶

    任务 1：Masked LM（带 MASK 的语言模型）

    • 随机抽取 15% 的 token 作为 MASK 对象，然后按比例处理：
    • 80% 概率：用 [MASK] 替换
    • 10% 概率：用一个随机单词替换
    • 10% 概率：保持不变

    为什么要保留 10% 不变、10% 随机替换？—— 因为真实使用时文本里没有 [MASK]，这样处理能让模型不依赖 [MASK] 标志，逼着它真正理解上下文。

    任务 2：Next Sentence Prediction（下一句预测）

    • 输入句子对 (A, B)，预测 B 是不是 A 的真实下一句
    • 50% 的 B 是真实下一句（IsNext 正样本）
    • 50% 的 B 是随机抽的一句（NotNext 负样本）

    2.5 BERT 数据集与关键参数¶

    • 数据集：BooksCorpus（8 亿词）+ English Wikipedia（25 亿词）
    参数 取值
    Transformer 层数 12
    特征维度 768
    head 数 12
    总参数量 1.15 亿

    2.6 AE 模型总结¶

    优点：BERT 用双向 Transformer，语言理解任务表现很好

    缺点： 1. 输入噪声：预训练（有 [MASK]）与微调（无 [MASK]）存在差异 2. 更适合 NLU，不适合 NLG（它是"看懂"的模型，不会"生成"）

    三、自回归模型（AR）—— 代表作 GPT¶

    3.1 什么是自回归模型¶

    • 特点：Decoder-Only（只用解码器）
    • 基本原理：从左往右学习的模型，只能利用上文（或下文）的信息
    • 通常用于生成式任务（NLG）：摘要、翻译、抽象问答，长文本生成能力强

    3.2 GPT 简介¶

    • 2018 年 6 月 OpenAI 发表论文《Improving Language Understanding by Generative Pre-training》
    • GPT = Generative Pre-training（生成式预训练），1.17 亿参数

    3.3 GPT 模型架构（单向！）¶

    核心区别：GPT 是单向 Transformer。

    • 预测单词 ui 时，GPT 只用 [u1...u(i-1)]（左边信息）
    • 而 BERT 会用 [u1...u(i-1), u(i+1)...un]（左右信息）

    Decoder Block 的改动： - 采用了 Transformer 的 Decoder 模块 - 但取消了第二个 encoder-decoder attention 子层，只保留： - Masked Multi-Head Attention 层（带掩码的多头注意力） - Feed Forward 层（前馈层） - 经典 Transformer 用 6 个 Decoder Block，GPT 用了 12 个

    3.4 GPT 训练过程（两阶段）¶

    阶段 1：无监督预训练语言模型

    • 目标：最大化似然函数——预测每个词 ui 的概率，基于它前面 ui-k 到 ui-1 的词
    • k 是上文窗口大小，k 越大，模型能获取的上文信息越充足，能力越强

    阶段 2：有监督的下游任务微调（fine-tuning）

    • 根据单词序列 [x1...xn] 预测标签 y，最大化目标函数
    • 不同任务定义不同输入、加不同分类层（分类/相似度/问答/推理等任务适配）

    3.5 GPT 数据集与关键参数¶

    • 数据集：BooksCorpus，约 5GB，7400 万+ 句子，7000 本不同风格书籍
    • 选它的原因：① 大量高质量长句，学习长距离依赖；② 书籍未开源，下游数据集中见不到，更能验证泛化能力
    参数 取值
    Transformer 层数 12
    特征维度 768
    head 数 12
    总参数量 1.17 亿

    3.6 AR 模型总结¶

    优点： 1. 擅长生成式任务 2. 生成数据比较容易

    缺点：不能完全捕捉 token 的内在联系（只能看左边）

    四、序列到序列模型（Encoder-Decoder）—— 代表作 T5¶

    4.1 什么是序列到序列模型¶

    • 同时使用编码器和解码器
    • 将每个 task 视作序列到序列的转换/生成（文本到文本、文本到图像、图像到文本）
    • 通常用于需要内容理解 + 生成的任务，比如机器翻译

    4.2 T5 简介¶

    • 由谷歌提出
    • 核心思想：任务统一框架——把所有 NLP 任务都视为文本转换任务（Text-to-Text）
    • 好处：用同样的模型、同样的损失函数、同样的训练过程、同样的解码过程完成所有 NLP 任务

    举例：翻译 = "把英文翻译成中文：xxx"；情感分析 = "这段文本情感是：xxx"。全部是"文本进、文本出"。

    4.3 T5 模型架构改动¶

    T5 结构与原始 Transformer 基本一致，改动点： 1. 简化版 Layer Norm：去掉 Layer Norm 的 bias；把 Layer Norm 放在残差连接外面 2. 简化版相对位置编码：每个位置编码是一个标量，加到 logits 上计算注意力权重；各层共享位置编码，但同一层内不同注意力头独立学习

    4.4 T5 预训练与微调¶

    • 自监督预训练：两种任务——Causal Language Modeling（因果语言建模）+ Masked Language Modeling（填空任务）
    • 多任务微调：利用标注数据进行有监督的多任务预训练（如 SQuAD 问答、机器翻译）

    4.5 T5 数据集与关键参数¶

    • 数据集：C4（Colossal Clean Crawled Corpus）——对 Common Crawl 过滤（去重复、去低质量、去代码类文本、只留英文）
    参数 取值
    Transformer 层数 24
    特征维度 768
    head 数 12
    总参数量 2.2 亿

    4.6 Encoder-Decoder 模型总结¶

    优点： 1. 能处理多种 NLP 任务，可扩展性好 2. 相比 GPT-2/GPT-3，T5 参数量少、训练更快

    缺点： 1. 训练时间长、需要更大算力 2. 模型可解释性不足

    五、大模型主流架构：为什么是 Decoder-only？¶

    结论：现在的主流大模型（GPT、LLaMA、Qwen、DeepSeek 等）基本都是 Decoder-only。

    原因：

    1. 训练效率与工程实现优势：Decoder-only 结构更简单，训练和部署更高效
    2. 理论原因：Encoder 的双向注意力存在低秩问题，可能削弱模型表达能力
    3. 对生成任务而言：引入双向注意力并无实质好处——生成本来就是从左往右的
    4. 参数量对比：Encoder-Decoder 架构在某些场景表现更好，大概只是因为它多了一倍参数；同等参数量、同等推理成本下，Decoder-only 就是最优选择

    总结¶

    问题 答案
    LLM 主要类别架构有哪些？ Encoder-Only、Decoder-Only、Encoder-Decoder
    自编码模型的基本原理？ 输入中随机 MASK 掉一部分单词，根据上下文预测这个词
    BERT 模型的核心架构？ Transformer 的 Encoder 模块
    BERT 的预训练任务？ MLM（掩码语言模型）+ NSP（下一句预测）
    自回归模型的基本原理？ 从左往右学习，只能利用上文或下文的信息
    GPT 模型的核心架构？ Transformer 的 Decoder 模块（去掉中间的第二个子层）
    GPT 的训练过程？ 无监督预训练 + 有监督任务微调
    序列到序列模型的基本原理？ 同时使用编码器和解码器，把每个任务视作序列到序列的转换/生成
    T5 的核心架构？ Transformer（Encoder-Decoder）

    一张表记住三大类：

    ┌──────────────────────────────────────────────────────────┐
│                     Transformer (2017)                    │
├──────────────┬──────────────┬─────────────────────────────┤
│  只用 Encoder │  只用 Decoder │  Encoder + Decoder          │
│  自编码 AE    │  自回归 AR     │  序列到序列                  │
│  BERT        │  GPT         │  T5                         │
│  "看懂"       │  "生成"       │  "翻译"                     │
│  NLU         │  NLG         │  理解+生成                   │
└──────────────┴──────────────┴─────────────────────────────┘
      ↓ 大模型时代几乎全部选择 ↓
        Decoder-only（生成任务最优）
