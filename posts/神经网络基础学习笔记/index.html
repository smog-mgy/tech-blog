    神经网络基础学习笔记¶

    日期：2026-04-16 标签：深度学习 · 神经网络 · 学习笔记

    一、什么是神经网络¶

    1.1 一句话定义¶

    人工神经网络（ANN，简称 NN）= 模仿生物神经网络结构和功能的计算模型。

    生物神经元的工作流程： - 树突接收输入信号 → 细胞核对信号加权求和、处理 → 轴突输出信号 - 电信号聚集到一定电位后细胞被激活，才发出信号

    类比：神经网络的神经元就是"加权求和 + 激活函数"：

    输入 x1,x2,x3（树突，每条线有权重 w） → 加权求和 z = w1x1+w2x2+... + b → 激活函数 f(z) → 输出 a

    1.2 神经网络的结构¶

    多个神经元组成网络，相邻层的神经元全连接（full connected），每个连接有一个权重：

    层 说明
    输入层（Input Layer） 输入 x 的那一层（图像、文本、声音等），每个特征对应一个神经元
    输出层（Output Layer） 输出 y 的那一层，根据任务（回归/分类）生成预测结果
    隐藏层（Hidden Layers） 输入输出之间的层，网络的"深度"由隐藏层数量决定

    全连接神经网络的特点： - 同一层的神经元之间没有连接 - 第 N 层的每个神经元和第 N-1 层的所有神经元相连 - 全连接网络接收二维数据 [batch_size, features]，每层之间以二维形式传递 - 第 N-1 层的输出 = 第 N 层的输入 - 每个连接都有权重（w 和 b）

    1.3 内部状态值和激活值¶

    每个神经元前向传播产生两个值：

    内部状态值：z = W·x + b        （加权求和的结果，反映输入和权重计算）
激活值：    a = f(z)           （内部状态值经过激活函数非线性变换后的输出）

    反向传播时则产生对应的两个梯度：激活值梯度和内部状态值梯度。

    二、激活函数¶

    2.1 为什么要激活函数？¶

    激活函数为网络注入非线性因素，让神经网络能拟合各种曲线。

    • 没有激活函数 → 再深的网络等价于一个线性模型（多层线性 = 线性）
    • 加了激活函数 → 网络可以逼近任意函数，提升对复杂问题的拟合能力

    2.2 Sigmoid（二分类输出层常用）¶

    import torch
import matplotlib.pyplot as plt

_, axes = plt.subplots(1, 2)
# 函数图像
x = torch.linspace(-20, 20, 1000)
y = torch.sigmoid(x)
axes[0].plot(x, y)
axes[0].grid()
axes[0].set_title('Sigmoid 函数图像')
# 导数图像
x = torch.linspace(-20, 20, 1000, requires_grad=True)
torch.sigmoid(x).sum().backward()
axes[1].plot(x.detach(), x.grad)   # x.detach() 取值，x.grad 求导
axes[1].grid()
axes[1].set_title('Sigmoid 导数图像')
plt.show()

    特点与坑： - 将输入映射到 (0, 1) 之间 - 输入 <-6 或 >6 时激活值几乎一样 → 丢失信息（输入 100 和 10000 输出都约等于 1） - 导数范围 (0, 0.25)，输入 <-6 或 >6 时导数接近 0 → 参数更新极其缓慢 - 5 层之内就会产生梯度消失；不以 0 为中心 - 现在实践很少用，一般只用于二分类的输出层

    ⚠️ 画图报错 OMP: Error #15: Initializing libiomp5md.dll 时，删除 anaconda3/Lib/site-packages/torch/lib 目录下的 libiomp5md.dll 文件即可。

    2.3 Tanh（隐藏层可用的备选）¶

    _, axes = plt.subplots(1, 2)
# 函数图像
x = torch.linspace(-20, 20, 1000)
y = torch.tanh(x)
axes[0].plot(x, y)
axes[0].grid()
axes[0].set_title('Tanh 函数图像')
# 导数图像
x = torch.linspace(-20, 20, 1000, requires_grad=True)
torch.tanh(x).sum().backward()
axes[1].plot(x.detach(), x.grad)
axes[1].grid()
axes[1].set_title('Tanh 导数图像')
plt.show()

    特点： - 输入映射到 (-1, 1)，以 0 为中心、在 0 点对称（优于 sigmoid） - 导数值范围 (0, 1)，比 sigmoid 梯度大 → 收敛更快，减少迭代次数 - 两侧导数也为 0 → 同样会梯度消失 - 常用搭配：隐藏层用 tanh，输出层用 sigmoid

    2.4 ReLU（隐藏层首选）¶

    _, axes = plt.subplots(1, 2)
# 函数图像
x = torch.linspace(-20, 20, 1000)
y = torch.relu(x)
axes[0].plot(x, y)
axes[0].grid()
axes[0].set_title('ReLU 函数图像')
# 导数图像
x = torch.linspace(-20, 20, 1000, requires_grad=True)
torch.relu(x).sum().backward()
axes[1].plot(x.detach(), x.grad)
axes[1].grid()
axes[1].set_title('ReLU 导数图像')
plt.show()

    特点： - x < 0 映射为 0，x > 0 保持不变 → 重视正信号、忽略负信号 - 运算简单（比 sigmoid 的指数运算省太多）→ 提高训练效率 - x > 0 时梯度不衰减 → 缓解梯度消失 - 目前最常用的激活函数 - 坑：随着训练推进，部分输入落入小于 0 区域，对应权重无法更新 → "神经元死亡"（Dead ReLU），注意学习率别设太大

    ReLU vs Sigmoid 的优势： 1. 计算量小（无指数运算） 2. 不轻易梯度消失，能训练深层网络 3. 使部分神经元输出为 0 → 网络稀疏、减少参数相互依赖 → 缓解过拟合

    2.5 Softmax（多分类输出层）¶

    softmax = sigmoid 在多分类上的推广，把多个输出变成概率（都在 (0,1) 且累和为 1），选概率最大的作为预测类别。

    import torch

scores = torch.tensor([0.2, 0.02, 0.15, 0.15, 1.3, 0.5, 0.06, 1.1, 0.05, 3.75])
# dim = 0，按行计算概率
probabilities = torch.softmax(scores, dim=0)
print(probabilities)

# 输出结果：
# tensor([0.0212, 0.0177, 0.0202, 0.0202, 0.0638, 0.0287, 0.0185, 0.0522,
#         0.0183, 0.7392])

    2.6 激活函数选择方法（背下来）¶

    隐藏层： 1. 优先 ReLU 2. ReLU 效果不好再试 Leaky ReLU 等 3. 用 ReLU 注意 Dead ReLU 问题（避免 0 梯度导致神经元死亡） 4. 少用 sigmoid，可尝试 tanh

    输出层： | 任务 | 激活函数 | |---|---| | 二分类 | sigmoid | | 多分类 | softmax | | 回归 | identity（恒等，即不加激活） |

    三、参数初始化¶

    3.1 常见初始化方式¶

    方式 说明 PyTorch API
    均匀分布初始化 默认区间 (0,1)，可设为 (-1/√d, 1/√d)（d=输入数量） nn.init.uniform_
    正态分布初始化 均值 0、标准差 1 的高斯分布取小值 nn.init.normal_(w, mean=0, std=1)
    全 0 初始化 所有权重初始化为 0 nn.init.zeros_
    全 1 初始化 所有权重初始化为 1 nn.init.ones_
    固定值初始化 所有参数为某个固定值 nn.init.constant_(w, 5)
    Kaiming / HE 初始化 适合 ReLU/Leaky ReLU nn.init.kaiming_normal_ / kaiming_uniform_
    Xavier / Glorot 初始化 适合 Sigmoid/Tanh nn.init.xavier_normal_ / xavier_uniform_

    3.2 Kaiming 和 Xavier 的计算公式¶

    Kaiming（HE）初始化（fan_in = 输入层神经元个数）： - 正态：从 [0, std] 抽取样本，std = sqrt(2 / fan_in) - 均匀：从 [-limit, limit] 抽取样本，limit = sqrt(6 / fan_in)

    Xavier（Glorot）初始化（fan_in = 输入个数，fan_out = 输出个数）： - 正态：std = sqrt(2 / (fan_in + fan_out)) - 均匀：limit = sqrt(6 / (fan_in + fan_out))

    3.3 代码演示¶

    import torch
import torch.nn as nn

# 1. 均匀分布随机初始化
linear = nn.Linear(5, 3)
nn.init.uniform_(linear.weight)          # (0,1) 均匀分布
print(linear.weight.data)

# 2. 固定值初始化
linear = nn.Linear(5, 3)
nn.init.constant_(linear.weight, 5)      # 全部为 5
print(linear.weight.data)

# 3. 全 0 初始化
linear = nn.Linear(5, 3)
nn.init.zeros_(linear.weight)
print(linear.weight.data)

# 4. 全 1 初始化
linear = nn.Linear(5, 3)
nn.init.ones_(linear.weight)
print(linear.weight.data)

# 5. 正态分布随机初始化
linear = nn.Linear(5, 3)
nn.init.normal_(linear.weight, mean=0, std=1)
print(linear.weight.data)

# 6. kaiming 初始化（ReLU 网络用它）
linear = nn.Linear(5, 3)
nn.init.kaiming_normal_(linear.weight)    # 正态版
nn.init.kaiming_uniform_(linear.weight)   # 均匀版
print(linear.weight.data)

# 7. xavier 初始化（Sigmoid/Tanh 网络用它）
linear = nn.Linear(5, 3)
nn.init.xavier_normal_(linear.weight)     # 正态版
nn.init.xavier_uniform_(linear.weight)    # 均匀版
print(linear.weight.data)

    3.4 初始化方法怎么选？¶

    • 按激活函数选：Sigmoid/Tanh → Xavier；ReLU/Leaky ReLU → Kaiming
    • 按网络深度选：浅层网络随机初始化即可；深层网络要考虑方差平衡 → Xavier 或 Kaiming
    • 一般用 PyTorch 构建模型时，每层参数有默认初始化；手动指定时优先 Kaiming / Xavier

    四、神经网络搭建和参数计算¶

    4.1 搭建方法（三板斧）¶

    在 PyTorch 中定义深度神经网络 = 层堆叠： 1. 继承 nn.Module 2. __init__ 方法中定义网络层结构（全连接层）并初始化 3. forward 方法中定义数据传递方式（前向传播），实例化模型时底层自动调用

    4.2 完整示例¶

    构建如下网络： - 第 1 隐藏层：Linear(3,3) + xavier 初始化 + sigmoid - 第 2 隐藏层：Linear(3,2) + kaiming 初始化 + relu - 输出层：Linear(2,2) + softmax（多分类归一化）

    import torch
import torch.nn as nn
from torchsummary import summary   # 计算参数/查看结构
# 安装：pip install torchsummary -i https://mirrors.aliyun.com/pypi/simple/

class Model(nn.Module):
    # 初始化属性值
    def __init__(self):
        super(Model, self).__init__()   # 调用父类初始化

        # 第一个隐藏层：3个输入特征，3个输出特征
        self.linear1 = nn.Linear(3, 3)
        nn.init.xavier_normal_(self.linear1.weight)   # xavier 初始化
        nn.init.zeros_(self.linear1.bias)

        # 第二个隐藏层：3个输入特征（上一层输出），2个输出特征
        self.linear2 = nn.Linear(3, 2)
        nn.init.kaiming_normal_(self.linear2.weight, nonlinearity='relu')
        nn.init.zeros_(self.linear2.bias)

        # 输出层：2个输入，2个输出
        self.out = nn.Linear(2, 2)

    # 前向传播方法
    def forward(self, x):
        x = self.linear1(x)
        x = torch.sigmoid(x)
        x = self.linear2(x)
        x = torch.relu(x)
        x = self.out(x)
        x = torch.softmax(x, dim=-1)   # dim=-1：每一行数据相加为1
        return x

if __name__ == "__main__":
    my_model = Model()
    my_data = torch.randn(5, 3)              # 随机产生数据：5个样本，3个特征
    print("mydata shape", my_data.shape)     # torch.Size([5, 3])

    output = my_model(my_data)
    print("output shape-->", output.shape)   # torch.Size([5, 2])

    # 计算模型参数（每层每个神经元的 w 和 b 个数总和）
    summary(my_model, input_size=(3,), batch_size=5)

    # 查看模型参数
    print("======查看模型参数w和b======")
    for name, parameter in my_model.named_parameters():
        print(name, parameter)

    输出结果：

output shape---> torch.Size([5, 2])

================================================================

Linear-2             [5, 2]          8

================================================================

    4.3 参数数量怎么算？¶

    输入数据 [batch_size, in_features] 经过网络 → 输出 [batch_size, out_features]。

    以第一个隐藏层为例（3 个神经元，输入 3 个特征）： - 每个神经元的参数 = 3 个 w + 1 个 b = 4 个 - 3 个神经元一共 = 3 × 4 = 12 个参数 ✓（对上表 Linear-1 的 12）

    重点：输入数据和网络权重是两个不同的事，算参数只数 w 和 b，不数输入数据。

    4.4 神经网络的优缺点¶

    优点 缺点
    精度高，性能优于其他 ML 方法，某些领域超人类 黑箱，很难解释模型怎么工作的
    可以近似任意非线性函数 训练时间长，需要大量算力
    框架和库丰富，生态好 网络结构复杂，要调超参数
    小数据集上表现不佳，容易过拟合

    五、损失函数¶

    5.1 什么是损失函数¶

    损失函数 = 衡量模型参数质量的函数，比较网络输出和真实输出的差异。

    • 损失值越小 → 模型参数越"好"
    • 目标：训练就是不断降低损失

    5.2 分类任务：多分类交叉熵（softmax 损失）¶

    多分类先用 softmax 把 logits 转成概率，再算交叉熵：

    L = -Σ y · log(S(f(x)))
    • y：样本属于某类别的真实概率
    • f(x)：预测分数（logits）
    • S：softmax 激活函数
    • L：损失结果

    从概率角度理解：最小化"正确类别对应预测概率的负对数"。

    PyTorch 实现：nn.CrossEntropyLoss()（注意：它 = softmax + 损失计算，不需要自己先 softmax）

    def test01():
    # 设置真实值：类别索引即可（不用 one-hot），类型必须是 int64
    y_true = torch.tensor([1, 2], dtype=torch.int64)
    # 预测值：网络输出的 logits（原始分数）
    y_pred = torch.tensor([[0.2, 0.6, 0.2], [0.1, 0.8, 0.1]],
                          requires_grad=True, dtype=torch.float32)
    # 实例化交叉熵损失
    loss = nn.CrossEntropyLoss()
    # 计算损失
    my_loss = loss(y_pred, y_true).detach().numpy()
    print('loss:', my_loss)

    5.3 分类任务：二分类交叉熵¶

    二分类不用 softmax，用 sigmoid，损失用二分类交叉熵。

    PyTorch 实现：nn.BCELoss()（输入必须是 sigmoid 输出的概率值）

    def test02():
    # 预测值是 sigmoid 输出的结果（0~1 概率）
    y_pred = torch.tensor([0.6901, 0.5459, 0.2469], requires_grad=True)
    y_true = torch.tensor([0, 1, 0], dtype=torch.float32)
    # 实例化二分类交叉熵损失
    loss = nn.BCELoss()
    my_loss = loss(y_pred, y_true).detach().numpy()
    print('loss：', my_loss)

    5.4 回归任务：MAE 损失（L1 Loss）¶

    MAE = mean(|y_true - y_pred|)   # 绝对误差作为距离

    特点： - 有稀疏性，为了惩罚较大的值，常作为正则项加到其他 loss 上 - 最大问题：梯度在零点不平滑，导致会跳过极小值

    PyTorch 实现：nn.L1Loss()

    def test03():
    y_pred = torch.tensor([1.0, 1.0, 1.9], requires_grad=True)
    y_true = torch.tensor([2.0, 2.0, 2.0], dtype=torch.float32)
    loss = nn.L1Loss()
    my_loss = loss(y_pred, y_true).detach().numpy()
    print('loss:', my_loss)   # (|1-2|+|1-2|+|1.9-2|)/3 = 0.7

    5.5 回归任务：MSE 损失（L2 Loss）¶

    MSE = mean((y_true - y_pred)²)   # 误差平方和的均值，也叫欧氏距离

    特点： - 也常作为正则项 - 预测值与目标值相差很大时，梯度容易爆炸（平方放大）

    PyTorch 实现：nn.MSELoss()

    def test04():
    y_pred = torch.tensor([1.0, 1.0, 1.9], requires_grad=True)

    5.6 回归任务：Smooth L1 损失¶

    Smooth L1 = 光滑之后的 L1，实际是分段函数（δ = f(x) - y）： - [-1, 1] 区间内：是 L2 损失 → 解决 L1 不光滑问题 - [-1, 1] 区间外：是 L1 损失 → 解决离群点梯度爆炸问题

    PyTorch 实现：nn.SmoothL1Loss()

    def test05():

    y_pred = torch.tensor([0.6, 0.4], requires_grad=True)
    loss = nn.SmoothL1Loss()
    my_loss = loss(y_pred, y_true).detach().numpy()
    print('loss:', my_loss)

    5.7 损失函数一览（背下来）¶

    任务 损失 PyTorch API 备注
    多分类 交叉熵（softmax 损失） nn.CrossEntropyLoss() 内部自带 softmax
    二分类 二分类交叉熵 nn.BCELoss() 输入需 sigmoid 概率
    回归 MAE (L1) nn.L1Loss() 零点不平滑
    回归 MSE (L2) nn.MSELoss() 大误差时梯度爆炸
    回归 Smooth L1 nn.SmoothL1Loss() 综合两者优点

    六、网络优化方法¶

    6.1 梯度下降算法回顾¶

    梯度下降 = 寻找使损失函数最小化的方法。 梯度的反方向是函数减少最快的方向：

    w = w - η * grad
    • η（学习率）太小 → 每次更新效果太小，训练时间成本大
    • η 太大 → 可能直接跳过最优解，进入无限训练
    • 解决：学习率也需要随训练变化（见 6.6 学习率衰减）

    6.2 Epoch、Batch、Iteration（三个概念）¶

    概念 含义
    Epoch 使用全部数据对模型进行一次完整训练（训练轮次）
    Batch_size 每次用训练集中的小部分样本做一次参数更新（每批次样本数量）
    Iteration 使用一个 Batch 数据对模型进行一次参数更新的过程

    算一算：数据集 50000 个样本，Batch Size = 256： - 每个 Epoch 训练样本数：50000 - 每个 Epoch 的 Batch 个数：50000/256 + 1 = 196（未整除 +1） - 每个 Epoch 的 Iteration 个数：196 - 10 个 Epoch 的 Iteration 个数：1960

    6.3 梯度下降的三种方式（按 Batch Size 区分）¶

    方式 Batch Size 说明
    批量梯度下降 BGD 全部样本 每轮更新一次，慢
    随机梯度下降 SGD 1 个样本 每样本更新一次，震荡大
    小批量梯度下降 Mini-Batch N/B（如 256） 最常用，折中

    6.4 反向传播（BP 算法）【了解】¶

    • 前向传播：数据输入网络，逐层向前传输，运算到输出层为止
    • 反向传播：利用损失 ERROR，从后往前，结合梯度下降，用链式法则依次求各个参数的偏导并更新

    简单例子（sigmoid 激活的两层网络）： - 求误差 E 对 w5 的导数：链式拆成 E对out_o1 → out_o1对net_o1 → net_o1对w5 - 求误差 E 对 w1 的导数：求导路径不止一条，把多条路径的导数加起来

    链式法则：∂E/∂w5 = ∂E/∂out_o1 × ∂out_o1/∂net_o1 × ∂net_o1/∂w5

    6.5 梯度下降的优化方法¶

    梯度下降可能遇到的问题： 1. 平缓区域：梯度值较小，参数优化变慢 2. 鞍点：梯度为 0，参数无法优化 3. 局部最小值：参数不是最优

    解决方案：Momentum、AdaGrad、RMSprop、Adam

    ① 指数加权平均（EWA，基础概念）¶

    参考各数值，距离越近权重越大、距离越远权重越小（就像明天气温跟昨天关系大，跟一个月前关系小）：

    St = β·St-1 + (1-β)·Yt
    • St：指数加权平均值
    • Yt：t 时刻的值
    • β：调节权重系数，β 越大曲线越平缓、波动越小（默认 0.9）
    import torch
import matplotlib.pyplot as plt

ELEMENT_NUMBER = 30

# 1. 实际平均温度
def test01():
    torch.manual_seed(0)
    temperature = torch.randn(size=[ELEMENT_NUMBER,]) * 10   # 30天随机温度
    days = torch.arange(1, ELEMENT_NUMBER + 1, 1)
    plt.plot(days, temperature, color='r')
    plt.scatter(days, temperature)
    plt.show()

# 2. 指数加权平均温度
def test02(beta=0.9):
    torch.manual_seed(0)
    temperature = torch.randn(size=[ELEMENT_NUMBER,]) * 10
    exp_weight_avg = []
    for idx, temp in enumerate(temperature, 1):
        if idx == 1:                     # 第一个元素 EWA = 自身
            exp_weight_avg.append(temp)
            continue
        # 上一个 EWA × β + 当前气温 × (1-β)
        new_temp = exp_weight_avg[idx - 2] * beta + (1 - beta) * temp
        exp_weight_avg.append(new_temp)
    days = torch.arange(1, ELEMENT_NUMBER + 1, 1)
    plt.plot(days, exp_weight_avg, color='r')
    plt.scatter(days, temperature)
    plt.show()

    ② Momentum 动量法¶

    梯度计算：s_t = β·s_t-1 + (1-β)·g_t
参数更新：w_t = w_t-1 - η·s_t
    • s_t：当前时刻指数加权平均梯度值（不再直接用当前梯度，而是历史梯度的加权平均）
    • β 通常取 0.9 或 0.99

    为什么能克服鞍点/震荡？ - 处于鞍点时当前梯度为 0，但 Momentum 已经积累了历史梯度，很可能跨过鞍点 - mini-batch 普通梯度下降容易震荡，Momentum 平滑了梯度变化 → 加快训练

    def test01():
    # 1. 初始化权重参数
    w = torch.tensor([1.0], requires_grad=True, dtype=torch.float32)
    loss = ((w ** 2) / 2.0).sum()
    # 2. 实例化优化方法：SGD 指定 momentum=0.9
    optimizer = torch.optim.SGD([w], lr=0.01, momentum=0.9)
    # 3. 第1次更新
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第1次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 输出：第1次: 梯度w.grad: 1.000000, 更新后的权重:0.990000
    # 4. 第2次更新
    loss = ((w ** 2) / 2.0).sum()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第2次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 输出：第2次: 梯度w.grad: 0.990000, 更新后的权重:0.971100

    ③ AdaGrad（自适应学习率）¶

    对不同参数分量使用不同学习率，学习率总体逐渐减小。

    步骤： 1. 初始化学习率 η、参数 w、小常数 σ = 1e-10 2. 初始化梯度累计变量 s = 0 3. 采样小批量计算梯度 g_t 4. 累积平方梯度：s_t = s_t-1 + g_t ⊙ g_t 5. 学习率：η / sqrt(s_t + σ) 6. 更新权重：w_t = w_t-1 - 学习率 × g_t

    缺点：可能使学习率过早、过量降低，训练后期学习率太小，难找到最优解。

    def test02():
    w = torch.tensor([1.0], requires_grad=True, dtype=torch.float32)
    loss = ((w ** 2) / 2.0).sum()
    optimizer = torch.optim.Adagrad([w], lr=0.01)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第1次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 输出：第1次: 梯度w.grad: 1.000000, 更新后的权重:0.990000
    loss = ((w ** 2) / 2.0).sum()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第2次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 输出：第2次: 梯度w.grad: 0.990000, 更新后的权重:0.982965

    ④ RMSProp（对 AdaGrad 的优化）¶

    用指数加权平均梯度替换历史梯度平方和，避免 AdaGrad 学习率过早降低的问题。

    def test03():

    loss = ((w ** 2) / 2.0).sum()
    # alpha 对应公式中的 beta
    optimizer = torch.optim.RMSprop([w], lr=0.01, alpha=0.9)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第1次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 输出：第1次: 梯度w.grad: 1.000000, 更新后的权重:0.968377
    loss = ((w ** 2) / 2.0).sum()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第2次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 输出：第2次: 梯度w.grad: 0.968377, 更新后的权重:0.945788

    ⑤ Adam（最常用）¶

    Adam = Momentum + RMSProp 的结合（自适应矩估计）： - Momentum：用梯度的指数加权平均 → 修正梯度 - RMSProp：用梯度平方的指数加权平均 → 修正学习率 - 计算梯度的一阶矩（平均值）和二阶矩（方差）的自适应估计，动态调整学习率

    def test04():

    loss = ((w ** 2) / 2.0).sum()
    # betas 是指数加权的系数（一阶矩、二阶矩）
    optimizer = torch.optim.Adam([w], lr=0.01, betas=[0.9, 0.99])
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第1次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 输出：第1次: 梯度w.grad: 1.000000, 更新后的权重:0.990000
    loss = ((w ** 2) / 2.0).sum()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第2次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 输出：第2次: 梯度w.grad: 0.990000, 更新后的权重:0.980003

    小结：实践中最常用 Adam（综合两者优点）；SGD 也能用但要配 momentum。

    6.6 学习率衰减策略¶

    为什么要衰减：学习率固定可能一直震荡或跳过最优点，训练中逐渐减小学习率，前期大步快走、后期小步精调。

    ① 等间隔衰减：StepLR¶

    import torch
import torch.optim as optim
import matplotlib.pyplot as plt

def test_StepLR():
    LR = 0.1
    iteration = 10
    max_epoch = 200
    # 1. 初始化参数
    y_true = torch.tensor([0])
    x = torch.tensor([1.0])
    w = torch.tensor([1.0], requires_grad=True)
    # 2. 优化器
    optimizer = optim.SGD([w], lr=LR, momentum=0.9)
    # 3. 设置学习率下降策略：每 50 轮 × 0.5
    scheduler_lr = optim.lr_scheduler.StepLR(optimizer, step_size=50, gamma=0.5)
    # 4. 记录学习率变化
    lr_list, epoch_list = list(), list()
    for epoch in range(max_epoch):
        lr_list.append(scheduler_lr.get_last_lr())
        epoch_list.append(epoch)
        for i in range(iteration):
            loss = ((w * x - y_true) ** 2) / 2.0
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
        scheduler_lr.step()          # 每个 epoch 更新学习率
    # 5. 绘制学习率变化曲线
    plt.plot(epoch_list, lr_list, label="Step LR Scheduler")
    plt.xlabel("Epoch")
    plt.ylabel("Learning rate")
    plt.legend()
    plt.show()

    调整方式：lr = lr * gamma（每 step_size 轮衰减一次）

    ② 指定间隔衰减：MultiStepLR¶

    def test_MultiStepLR():
    torch.manual_seed(1)
    LR = 0.1
    iteration = 10
    max_epoch = 200
    weights = torch.randn((1), requires_grad=True)
    target = torch.zeros((1))
    optimizer = optim.SGD([weights], lr=LR, momentum=0.9)
    # 指定在哪些轮次衰减
    milestones = [50, 125, 160]
    scheduler_lr = optim.lr_scheduler.MultiStepLR(optimizer, milestones=milestones, gamma=0.5)
    lr_list, epoch_list = list(), list()
    for epoch in range(max_epoch):
        lr_list.append(scheduler_lr.get_last_lr())
        epoch_list.append(epoch)
        for i in range(iteration):
            loss = torch.pow((weights - target), 2)
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
        scheduler_lr.step()
    plt.plot(epoch_list, lr_list, label="Multi Step LR Scheduler\nmilestones:{}".format(milestones))
    plt.xlabel("Epoch")
    plt.ylabel("Learning rate")
    plt.legend()
    plt.show()

    调整方式：在 milestones 指定的轮次（如 50/125/160）lr = lr * gamma

    ③ 指数衰减：ExponentialLR¶

    def test_ExponentialLR():
    LR = 0.1
    iteration = 10
    max_epoch = 200
    y_true = torch.tensor([0])
    x = torch.tensor([1.0])
    w = torch.tensor([1.0], requires_grad=True)
    optimizer = optim.SGD([w], lr=LR, momentum=0.9)
    gamma = 0.95
    scheduler_lr = optim.lr_scheduler.ExponentialLR(optimizer, gamma=gamma)
    lr_list, epoch_list = list(), list()
    for epoch in range(max_epoch):
        lr_list.append(scheduler_lr.get_last_lr())
        epoch_list.append(epoch)
        for i in range(iteration):
            loss = ((w * x - y_true) ** 2) / 2.0
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
        scheduler_lr.step()
    plt.plot(epoch_list, lr_list, label="Exponential LR Scheduler")
    plt.xlabel("Epoch")
    plt.ylabel("Learning rate")
    plt.legend()
    plt.show()

    调整方式：lr = lr * gamma^epoch（每个 epoch 都衰减，曲线平滑下降）

    三种策略小结：

    策略 API 调整方式
    等间隔衰减 StepLR(opt, step_size, gamma) 每 step_size 轮 × gamma
    指定间隔衰减 MultiStepLR(opt, milestones, gamma) 在指定轮次 × gamma
    指数衰减 ExponentialLR(opt, gamma) 每轮 × gamma^epoch

    七、正则化方法¶

    7.1 什么是正则化¶

    正则化 = 一系列减小测试误差（提高泛化能力）的策略。

    • 神经网络表示能力强 → 容易过拟合 → 需要正则化
    • 深度学习常用策略：范数惩罚、Dropout、特殊的网络层（如 BN）

    7.2 Dropout（随机失活）¶

    思想：训练时让神经元以概率 p 停止工作（激活置 0），未置 0 的缩放 1/(1-p)。 - 训练过程 = 对完整神经网络的一些子集进行训练，每次只更新子网络参数 - 测试过程中随机失活不起作用

    import torch
import torch.nn as nn

def test():
    # 初始化随机失活层：p=0.4，即 40% 神经元失活
    dropout = nn.Dropout(p=0.4)
    # 输入数据：某一层的输出
    inputs = torch.randint(0, 10, size=[1, 4]).float()
    layer = nn.Linear(4, 5)
    y = layer(inputs)
    y = torch.relu(y)
    print("未失活FC层的输出结果：\n", y)
    # tensor([[0.0000, 1.8033, 1.4608, 4.5189, 6.9116]])
    y = dropout(y)
    print("失活后FC层的输出结果：\n", y)
    # tensor([[0.0000, 3.0055, 2.4346, 7.5315, 11.5193]])
    # 部分变 0，没变 0 的按 1/(1-0.4)≈1.67 放大

    7.3 批量归一化（Batch Normalization，BN）¶

    先对数据标准化，再对数据重构（缩放+平移）：

    y = λ·(x - E(x)) / sqrt(Var(x) + eps) + β
    • λ 和 β：可学习参数，对标准化后的值做线性变换（λ 系数、β 偏置）
    • eps：通常 1e-5，避免分母为 0
    • E(x)：均值；Var(x)：方差
    • 批量归一化层在计算机视觉领域使用较多
    import torch
import torch.nn as nn

m = nn.BatchNorm2d(2, eps=1e-05, momentum=0.1, affine=True)  # affine=True 表示使用 weight 和 bias
input = torch.randn(1, 2, 3, 4)
print("input-->", input)
output = m(input)
print("output-->", output)      # 输出被标准化+缩放平移
print(output.size())            # torch.Size([1, 2, 3, 4])
print(m.weight)                 # 可学习参数，初始 [1., 1.]
print(m.bias)                   # 可学习参数，初始 [0., 0.]

    dataloader = DataLoader(train_dataset, shuffle=True, batch_size=8)
    # 初始化模型
    model = PhonePriceModel(input_dim, class_num)
    # 损失函数：多分类交叉熵
    criterion = nn.CrossEntropyLoss()
    # 优化方法
    optimizer = optim.SGD(model.parameters(), lr=1e-3)
    # 训练轮数
    num_epoch = 50

    for epoch_idx in range(num_epoch):
        start = time.time()
        total_loss = 0.0
        total_num = 0
        for x, y in dataloader:
            # 将数据送入网络进行预测
            output = model(x)
            # 计算损失
            loss = criterion(output, y)
            # 梯度清零
            optimizer.zero_grad()
            # 反向传播
            loss.backward()
            # 参数更新
            optimizer.step()
            total_num += 1
            total_loss += loss.item()
        print('epoch: %4s loss: %.2f, time: %.2fs' % (epoch_idx + 1, total_loss / total_num, time.time() - start))
    # 模型保存
    torch.save(model.state_dict(), 'model/phone.pth')

if __name__ == '__main__':
    train_dataset, valid_dataset, input_dim, class_num = create_dataset()
    train(train_dataset, input_dim, class_num)

    def test(valid_dataset, input_dim, class_num):
    # 加载模型和训练好的网络参数
    model = PhonePriceModel(input_dim, class_num)
    model.load_state_dict(torch.load('model/phone.pth'))
    # 构建加载器
    dataloader = DataLoader(valid_dataset, batch_size=8, shuffle=False)
    correct = 0
    for x, y in dataloader:
        output = model(x)
        # 获取类别结果：取概率最大的下标
        y_pred = torch.argmax(output, dim=1)
        # 累计预测正确的个数
        correct += (y_pred == y).sum()
    # 求预测精度
    print('Acc: %.5f' % (correct.item() / len(valid_dataset)))
    # 输出：Acc: 0.64250

if __name__ == '__main__':

    结尾 · 总结¶

    整体流程：

    数据集构建 → 模型构建 → 模型训练 → 模型预测

    本章核心知识点一览： - 神经网络 = 输入层 + 隐藏层 + 输出层，全连接结构，神经元 = 加权和 + 激活函数 - 激活函数：隐藏层用 ReLU，输出层二分类 sigmoid / 多分类 softmax / 回归恒等 - 参数初始化：Sigmoid/Tanh → Xavier；ReLU → Kaiming - 损失函数：分类用交叉熵（多分类 CrossEntropyLoss / 二分类 BCELoss），回归用 L1 / MSE / SmoothL1 - 优化：Epoch/Batch/Iteration 概念；Momentum / AdaGrad / RMSProp / Adam；学习率衰减 StepLR / MultiStepLR / ExponentialLR - 正则化：Dropout（随机失活）、BN（批量归一化）
