    关于我¶

    我是苗国艺，郑州西亚斯学院数据科学与大数据技术专业 2027 届本科生，正在学习 AI Agent 应用开发。

    我在关注什么¶

    主要围绕 Python 后端、RAG、工具调用和工作流编排做个人项目。近期用 RepoLaunch 练习从仓库分析、容器运行到失败诊断的完整过程；用 OpsDesk 练习设备运维场景中的知识问答和工单流程。

    为什么留下这些记录¶

    刚开始学习时，很多知识停留在“看过”和“跑过例子”。真正接到项目里，才发现配置、依赖、权限和验证方法同样需要花时间理解。

    我希望每篇文章留下一个明确问题，以及当时使用的依据、做过的取舍和还没有解决的部分。基础内容放在学习笔记，项目设计放在专题，范围较小的故障放在排错记录。

    项目与联系¶

    欢迎通过对应项目的 GitHub Issues 讨论具体问题。代码、报告和复现步骤能帮助我更准确地理解反馈。
