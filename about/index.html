    关于我¶

    我是一名 27 届双非本科在读学生，正在学习 AI Agent 应用开发。

    我在做什么¶

    • 方向：Python / 大模型应用 / RAG / Agent 开发
    • 目前在做：电气自动化运维工作，业余时间坚持自学技术
    • 这个博客：记录我学习、踩坑、做项目的全过程

    为什么写这个博客¶

    找工作这件事给我上了一课。

    原本计划大三下学期开始实习，目标是 AI Agent 开发方向。真正开始时才发现：秋招已经开始了，身边的同学大多已经攒下了几段实习，而我既没有实习经历，学过的东西也零散，知识体系混乱，简历上没什么可写。

    投了一周简历没有回音，人会变得麻木。那阵子很迷茫：起步晚了，还来不来得及？

    后来我先去做了一份电气自动化运维的工作。一开始依然迷茫，不知道这条路对不对，也不知道方向在哪。但做了一段时间后慢慢想明白一件事 ——不管在什么岗位上，持续学习和提升自己总是没错的。

    所以这个博客不装大牛，也不写我没搞懂的东西。它记录的就是一个普通学生从迷茫到慢慢找方向的过程：踩过的坑、跑通的项目、搞懂的原理。如果你也在经历类似的阶段，希望这些记录能帮到你。
